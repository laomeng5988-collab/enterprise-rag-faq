# 智联协同（ZhiLink）安全与合规

智联协同将数据安全与合规置于产品设计的核心，通过了多项权威认证。

## 数据加密
- 传输加密：所有数据在传输过程中使用 TLS 1.3 加密。
- 存储加密：数据在静态存储时使用 AES-256 加密。
- 密钥管理：加密密钥由独立密钥管理系统托管，定期轮换。

## 访问控制
- 支持单点登录（SSO），可对接 SAML 2.0、OIDC 等标准协议。
- 支持多因素认证（MFA），可绑定手机验证码、TOTP 或硬件密钥。
- 管理员可设置 IP 白名单，限制仅允许指定网络访问。
- 详细的审计日志记录每一次登录与关键操作，支持导出。

## 数据驻留与备份
- 企业版支持选择数据驻留地域（中国大陆、新加坡、欧洲等）。
- 数据每日自动备份，备份保留 30 天，可执行灾难恢复演练。
- 提供 99.9% 的可用性服务等级协议（SLA）。

## 合规认证
- 通过 ISO 27001 信息安全管理体系认证。
- 通过 SOC 2 Type II 审计。
- 符合《中华人民共和国数据安全法》与《个人信息保护法》要求。
- 已备案三级等保（网络安全等级保护三级）。

## 隐私与数据权利
- 用户可随时导出或删除自己的全部数据（数据可携带权）。
- 处理个人信息遵循「最小必要」原则，仅收集服务所必需的信息。
- 不向第三方出售任何用户数据；第三方处理均签署数据处理协议（DPA）。

## 安全事件响应
- 设有 7×24 小时安全运营中心（SOC），实时监控异常。
- 发现安全事件后 72 小时内通知受影响的客户。
- 定期进行渗透测试与红队演练，持续修复漏洞。
